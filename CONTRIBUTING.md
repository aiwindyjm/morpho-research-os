# Contributing

Morpho is built in public by one maintainer and AI-assisted tooling. Start with an Issue or Discussion for non-trivial work. Use branches `feat/<scope>`, `fix/<scope>`, or `docs/<scope>` and conventional prefixes (`feat:`, `fix:`, `docs:`, `test:`, `chore:`).

Before coding, read `AGENTS.md`, `DO_NOT_BREAK.md`, and the governing spec. PRs must include What, Why, Changes, Tests, Documentation, and Breaking Changes. AI-generated changes are welcome but require human review; schema, security, persistence, provider, and architecture changes always require maintainer review.

Never include API keys, private research data, or real provider calls in tests. Small reproducible fixtures are preferred.
