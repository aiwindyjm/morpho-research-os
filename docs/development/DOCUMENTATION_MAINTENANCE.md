# Documentation Maintenance

Feature → update README status, roadmap, relevant concept/guide, changelog, and both README languages. Install/config changes → Quick Start and reference. Architecture/schema/provider/UI changes → governing docs, ADR or registry, and tests. CI checks that README.md and README.zh-CN.md contain the same major headings and flags likely version/status drift.

Task progress → update the matching row in `docs/development/TASK_STATUS.md` when the public state changes. Set `Review` only when a public PR exists, and set `Merged` only after the acceptance checks pass. Do not put private dates, daily quotas, local branch names, conversation journals, or unpublished batch plans in the ledger.
