# Morpho Documentation Map

This repository is documentation-first during Architecture Phase. Read the documents in this order:

1. `../README.md` — project promise and current status.
2. `../AGENTS.md` and `../DO_NOT_BREAK.md` — rules for AI-assisted changes.
3. `ARCHITECTURE.md` and `ARCHITECTURE_INVARIANTS.md` — system boundaries.
4. `DATA_MODEL.md`, `API.md`, and `data/` — contracts and persistence.
5. `frontend/` — design system and UI construction rules.
6. `development/` — GitHub, release, contribution, and public-development workflow.

The detailed product brief remains `../prd.md` until it is migrated into structured product documents.
