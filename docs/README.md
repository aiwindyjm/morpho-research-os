# Morpho Documentation Map

This repository is documentation-first during Architecture Phase. Read the documents in this order:

1. `../README.md` — project promise and current status.
2. `../AGENTS.md` and `../DO_NOT_BREAK.md` — rules for AI-assisted changes.
3. `PRD.md` — the single product and technical specification.
4. `ARCHITECTURE.md`, `ARCHITECTURE_INVARIANTS.md`, and `architecture/` — system boundaries.
5. `DATA_MODEL.md`, `API.md`, and `data/` — contracts and persistence.
6. `frontend/` — design system and UI construction rules.
7. `development/` — GitHub, release, contribution, and public-development workflow.

`PRD.md` is the only product and technical specification. Supporting documents may add implementation detail but must not create competing product versions.
